# Antigravity

`agy` reads `AGENTS.md` by itself; this file holds only what is specific to Antigravity.

- The project hook (`.agents/hooks.json` → `.agents/hooks/guard-agy.sh`) checks
  `run_command`, `view_file`, `list_dir`, `find_by_name`, `grep_search`, `write_to_file`,
  `replace_file_content` and `multi_replace_file_content`. It answers `force_ask` (the user
  is consulted every time) or `deny` (hard block); the reason starts with `guard:`. Every
  `ask`/`deny` is appended to `.claude/logs/guard.log` (git-ignored). Inspect hooks with `/hooks`.
- File tools to use instead of the shell: `view_file`, `list_dir`, `find_by_name` and
  `grep_search` to read; `write_to_file`, `replace_file_content` and
  `multi_replace_file_content` to write. A `deny` names the tool to use: follow it instead of
  retrying in the shell.
- Antigravity permission settings are global (`~/.gemini/antigravity-cli/settings.json`)
  and not versioned. Never write to `~/.gemini`: the user installs the template
  `.agents/agy-settings.example.json` by hand.
- `.agents/skills/` and `.agents/workflows/` are generated by OpenSpec; do not edit them by hand.
