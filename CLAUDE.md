# Claude Code

- A `PreToolUse` hook (`.claude/hooks/guard.sh`) checks `Bash`, `Read`, `Glob`, `Grep`,
  `Edit`, `Write` and `NotebookEdit`. A message starting with `guard:` comes from it:
  `ask` means the user is being consulted, `deny` is a hard block. Every `ask`/`deny` is
  appended to `.claude/logs/guard.log` (git-ignored).
- Changes to `.claude/settings.json` or the hook take effect only after restarting the
  session. Check them with `/hooks` and `/permissions`.
- A `deny` from the guard names the tool to use instead (`Read`, `Grep`, `Glob`, `Edit`,
  `Write`) or asks for one command per call: follow it instead of retrying in the shell.
- Commit with several `-m` flags instead of `$(cat <<EOF)`: command substitution asks.
- `.claude/settings.local.json` is personal and git-ignored.
- `.claude/skills/` and `.claude/commands/` are generated by OpenSpec; do not edit them by hand.
